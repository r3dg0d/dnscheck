# Contributing

Thanks for helping improve dnscheck.

## Development

```bash
cargo build
cargo test
cargo run -- status
cargo run -- report --json
```

## Guidelines

- Prefer honest limitations over overstated claims
- Add unit tests for parsers and classifiers
- Keep clap help text accurate
- Run `cargo fmt` and `cargo clippy` before sending a PR
- MIT license for all contributions

## Code of conduct

Be respectful. No harassment or malicious patches.
